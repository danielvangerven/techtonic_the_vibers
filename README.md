## Backend (API)

Demo logins (synthetic data): **thomas / tokyo2026** and **lucas / mechelen2026**.
Each user's moments are detected from their own calendar and transactions (`data/personas.json`,
generated by `scripts/generate.py`); logging in again starts the demo fresh.

| Route | What it does |
| --- | --- |
| `POST /api/login` `{username, password}` · `DELETE /api/login` | Log in (signed cookie) · log out |
| `GET /api/me` | `{ id, name }` of the logged-in user |
| `GET /api/timeline` | `MomentView[]` with checks, peer stats and recommendations |
| `GET` / `DELETE /api/moments/[id]` | One moment · "that's wrong" (404 for someone else's moment) |
| `POST /api/moments/[id]/resolve` `{productId}` | Activate a product; returns the updated `MomentView` |
| `POST /api/calendar/import` `{events}` | Extra calendar events → new or changed moments |
| `POST /api/tell` `{text}` | Free text → moment |
| `GET /api/peers?type=&country=` | Peer stats (min. group of 50) |
| `POST /api/voice` `{text}` | ElevenLabs briefing (simulated without an API key) |

Every route returns 401 without a session. Tests: `npx tsx scripts/test-detect.ts`.
